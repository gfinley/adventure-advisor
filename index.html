Connect Live Research Backend

Your live research backend runs on Google Cloud Run (paid by your Google AI Ultra monthly Cloud credits), verifies your Google Sign-In ID token server-side (locked exclusively to matthewgfinley@gmail.com), spawns 3 parallel Google-Search-grounded Gemini agents, and auto-commits results into gfinley/adventure-advisor.

Quick 5-Minute Deployment Checklist

  1. Claim your monthly Google AI Ultra Cloud credits in Google AI Studio and generate a GEMINI_API_KEY.
  2. Create a Web OAuth Client ID in Cloud Console with JavaScript origin https://gfinley.github.io.
  3. Create a fine-grained GitHub PAT scoped only to gfinley/adventure-advisor (Contents: Read & Write).
  4. Run ./backend/deploy.sh from Google Cloud Shell — it stores secrets in Secret Manager and deploys Cloud Run (scales to 0 when idle).
  5. Paste the resulting Cloud Run URL & Client ID above (or commit them in config.js for every device).
